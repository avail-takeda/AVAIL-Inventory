# AVAIL 棚卸 Webアプリ（GASなし）

スマートフォンの通常のHTTPSページとして動作する、AVAIL向け棚卸アプリです。

## 主な機能
- 棚番号 A-01 ～ N-05 ＋ 枝番号 1 ～ 9（例：A-01-1）
- JANコードのライブカメラ読み取り
- 写真撮影からのJAN読み取り
- 数量入力時に数字キーボード
- 登録後も棚番号・枝番号を維持
- 同じJANを複数回登録しても別レコード
- 入力済みデータの編集・削除
- localStorageで自動保存・復元
- CSV形式：棚番号,JANコード,数量
- ファイル名：YYMMDD_最初の棚番号.csv
- iPhoneの共有メニュー対応
- PWA（ホーム画面追加）対応

## 今回の構成
GASは使用しません。カメラをGAS HTML Serviceのiframe環境から切り離し、通常のHTTPSページで実行します。

CSVは端末上で生成します。iPhoneでは共有メニューからGoogle Drive等へ保存できます。

## 公開
GitHub Pages / Cloudflare Pagesなど、HTTPSで公開できる静的ホスティングへこのフォルダをそのままアップロードしてください。

## 注意
ZXingライブラリはunpkg CDNから読み込んでいます。完全オフライン化する場合はライブラリをローカル同梱する構成へ変更できます。

## 枝番号
棚番号の右側にある「枝番号」で 1 ～ 9 を選択できます。
未選択の場合は「A-01」、1を選択した場合は「A-01-1」のように記録されます。
CSVにも完成した棚番号（例：A-01-1）がそのまま出力されます。
