# AVAIL 棚卸 Webアプリ（GASなし）

スマートフォンの通常のHTTPSページとして動作する、AVAIL向け棚卸アプリです。

## 主な機能
- 棚番号 A-1 ～ N-05 ＋ 枝番号 1 ～ 9（例：A-1-1）
- JANコードのライブカメラ読み取り
- 写真撮影からのJAN読み取り
- 数量入力時に数字キーボード
- 登録後も棚番号・枝番号を維持
- 同じJANを複数回登録しても別レコード
- 入力済みデータの編集・削除
- localStorageで自動保存・復元
- CSV形式：棚番号,JANコード,数量
- ファイル名：YYMMDD_最初の棚番号.csv
- iPhoneの共有メニュー対応
- PWA（ホーム画面追加）対応

## 今回の構成
GASは使用しません。カメラをGAS HTML Serviceのiframe環境から切り離し、通常のHTTPSページで実行します。

CSVは端末上で生成します。iPhoneでは共有メニューからGoogle Drive等へ保存できます。

## 公開
GitHub Pages / Cloudflare Pagesなど、HTTPSで公開できる静的ホスティングへこのフォルダをそのままアップロードしてください。

## 注意
ZXingライブラリはunpkg CDNから読み込んでいます。完全オフライン化する場合はライブラリをローカル同梱する構成へ変更できます。

## 枝番号
棚番号の右側にある「枝番号」で 1 ～ 9 を選択できます。
未選択の場合は「A-1」、1を選択した場合は「A-1-1」のように記録されます。
CSVにも完成した棚番号（例：A-1-1）がそのまま出力されます。

## 今回の最終版の変更点
- 棚番号は `A-1` ～ `N-5` の1桁表記（先頭の0なし）
- 棚番号の右側に「枝番号」項目を表示
- 枝番号は「なし / 1 ～ 9」を選択可能
- 例：棚番号 `A-1` ＋ 枝番号 `1` → `A-1-1`
- ヘッダー中央に「棚卸リーダー」を表示
- ヘッダー左側にロゴ表示エリアを追加
- 設定（⚙）からロゴ画像を選択・変更・削除可能
- ロゴは端末のlocalStorageに保存（サーバーへ送信しません）
- 旧形式の `A-1` データを編集した場合も `A-1` に変換して扱えます

## タイトル・ロゴ設定
- 設定画面でアプリタイトルを入力・保存できます。
- 保存したタイトルはヘッダー中央に表示され、端末内に保存されます。
- ロゴはヘッダーの高さに合わせて縦横比を維持して自動縮小表示します。

## 共通設定
`config.js` で全ユーザー共通のタイトルとロゴを設定できます。

現在のタイトル：
`Buck Stock Counter`

ロゴをGitHubリポジトリに `logo.png` として追加した場合は、
`config.js` の `logo: ""` を `logo: "logo.png"` に変更してください。


## v6 共通タイトル・ロゴ
タイトルとロゴは `config.js` で管理します。現在のタイトルは `Buck Stock Counter`、ロゴはリポジトリ内の `logo.png` です。GitHub上で `config.js` や `logo.png` を更新してPagesを再デプロイすると、同じURLを利用する全ユーザーに反映されます。端末ごとのタイトル・ロゴ設定画面は廃止しています。
